# AgentHarnessLab 课程文章目录

计划共 **20 篇**。第 01 篇已有正文与配套源码，对应「最小实战：完成一次工具调用与任务交付」；真实模型效果尚未验证，其余文章与功能仍在规划。实际写作时可按篇幅拆分。

## 我们最终做成什么

课程交付一个使用 Python 实现、提供 CLI 入口的 Agent Harness 应用：装配模型与工具，驱动执行循环，管理上下文和会话；实现权限审批、停止、恢复、受控的子任务协作与结果验证。使用 uv 管理环境与依赖，以 DeepSeek 为主要模型接入。课程围绕信息获取、工具执行和结果交付安排实战；第一篇读取示例项目文件，用于展示模型如何获得真实资料。

读者需要具备 Python、Git 和命令行基础。已有的《深入 DeepSeek Harness：Cordis 如何组合 Agent 的能力》可作为背景阅读，不计入本系列篇数；本系列采用 Python 接口和显式装配，不直接使用 Node.js 的 Cordis。

阶段目标：会话有可靠记录，长任务可以压缩上下文、中断后恢复，并按需使用跨任务信息。

| 编号 | 文章标题 | 核心问题与动手成果 |
| --- | --- | --- |
| 09 | 关掉终端之后，任务还在吗：会话日志与状态重建 | 保存用户输入、模型输出、工具调用及结果；从事件记录重建任务状态，关联补丁和报告等文件产物。 |
| 10 | 任务没完成，上下文满了：压缩时必须保留什么 | 实现可追踪的上下文压缩，保留目标、决策、未完成工作和工具调用关系；验证压缩后的任务仍能继续。 |
| 11 | 从断点继续：恢复任务为什么不等于重放工具 | 实现检查点和恢复入口，区分已完成、待执行及结果不确定的调用；用崩溃场景验证不会盲目重复有副作用的操作。 |
| 12 | 跨任务记住什么：长期记忆的写入、检索与遗忘 | 保存经确认的项目约定，限定记忆作用范围，支持更新与删除；验证过期或无权限的信息不会进入模型输入，不扩展为完整 RAG 教程。 |

## 每篇文章的交付约定

- 从一个真实任务或失败现象开始，说明本篇要解决的问题。
- 提供关键实现、可运行命令、实际结果及已知限制，正文不堆砌完整源码。
- 配套代码固定到 commit 或 tag；未实现的命令和输出必须标为设计示例。
- 默认检查不调用真实模型；需要 API Key 和费用的实验在执行前说明。
- 安全限制与结果验证从第一篇开始；学习者对自己编写或由 AI 生成的实现进行代码审查，后续专题进一步展开。
- 每篇安排一个独立练习，每阶段提供验收任务；毕业验收使用未在正文逐步演示过的需求。
