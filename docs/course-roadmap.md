# 课程路线

课程聚焦 Agent Harness 应用开发：通过 CLI 运行 Agent Harness 应用，完成任务执行与结果验证。课程通过文件分析、工具执行和结果交付等任务演示运行机制，能力设计面向不同业务场景。

完整的 **20 篇文章** 标题、核心问题、动手成果及写作约定统一维护在 [课程文章目录](articles/README.md)。文章正文也放在 `docs/articles/` 下。

当前完成工程初始化，第 01 篇文章及配套只读工具调用示例已完成，真实模型效果尚未验证，其余正文与项目中的 Agent 功能仍处于规划阶段。完整 RAG 与自建模型推理部署作为独立课程方向。
